# 🏙️ CivicSense AI – From Complaints to Action

**An AI-Powered Civic Complaint Management System**

CivicSense AI is a smart platform that helps citizens report civic issues and enables authorities to manage, prioritize, and track complaints efficiently.

## ✨ Key Features

- Submit and manage civic complaints.
- AI-based complaint categorization and summarization.
- Identify duplicate complaints.
- Detect complaint priority.
- Track complaint status.
- Admin complaint management.
- Complaint statistics and analytics.

## 🛠️ Technology Stack

- **Language:** Java 21
- **Backend:** Spring Boot 3.3.4
- **Database:** H2 Database
- **ORM:** Spring Data JPA, Hibernate
- **Frontend:** HTML, CSS, JavaScript
- **Build Tool:** Maven

## ⚙️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR-USERNAME/CivicSense-AI.git
   ```
2. Open the project in your Java IDE.
3. Run `CivicSenseApplication.java`.
4. Visit `http://localhost:8080`.

## 🗄️ Database

Access the H2 database console:

`http://localhost:8080/h2-console`

- JDBC URL: `jdbc:h2:mem:civicsensedb`
- Username: `SA`
